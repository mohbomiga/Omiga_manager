OMIGA MANAGER - النسخة الأولية
================================

الموجود حالياً:
- تسجيل حساب وتسجيل دخول بالبريد وكلمة المرور عبر Supabase Auth.
- تسجيل الصيانة، بيع المنتجات، المصروفات، ومشتريات المخزون.
- لوحة شهرية للإيرادات وتكلفة المبيعات/قطع الغيار والمصروفات وصافي الربح.
- حذف حركة، فلتر شهر، وتصدير CSV.
- واجهة قابلة للتثبيت كتطبيق PWA على الآيفون والكمبيوتر.

مهم:
هذه نسخة أولية تحتاج إعداد Supabase واستضافتها على HTTPS قبل الاستخدام الفعلي.
لا تدخل بيانات مالية حقيقية قبل إتمام الإعداد واختبار الدخول والمزامنة.

الخطوات:
1) أنشئ مشروعاً في https://supabase.com
2) من SQL Editor نفّذ محتوى schema.sql.
3) من Project Settings > API انسخ Project URL و anon/public key.
4) افتح config.js وضع القيم مكان PASTE...
   لا تستخدم service_role key ولا تشاركه مع أي شخص.
5) ارفع كل الملفات إلى استضافة HTTPS مثل GitHub Pages.
6) افتح رابط التطبيق وأنشئ حساباً. إذا كان تأكيد البريد مفعلاً، أكّد البريد أولاً.
7) افتح الرابط على الآيفون والكمبيوتر وسجّل الدخول بنفس الحساب.

إضافة للآيفون:
Safari > زر المشاركة > Add to Home Screen.

ملاحظات محاسبية:
- الصيانة والبيع: amount = المقبوض، cost = تكلفة القطع/البضاعة المستخدمة أو المباعة.
- المصروف: amount = المبلغ المدفوع.
- شراء بضاعة: amount = إجمالي المبلغ المدفوع للمخزون.
- شراء البضاعة لا يخصم من صافي الربح في لوحة الشهر؛ تكلفة المنتج تخصم عند تسجيل بيعه في خانة التكلفة.
- لا تسجل شراء المخزون كمصروف مرة أخرى حتى لا يتكرر الخصم.
- النسخة الحالية لا تتضمن بعد إدارة كميات المخزون، الديون، الأقساط، أو صلاحيات الموظفين.
